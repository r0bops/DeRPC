DeRPC private, verified Ethereum reads

Every read goes through Anon-RPC (the tor-js worker) to operators you choose, and is checked against a light client before it is shown. Reads that can't be proven are refused, and nothing ever falls back to a direct connection. This page uses only the public provider API, through viem. Also: integrator example · network check.

2 · Choose your operators

      

        DeRPC never picks operators for you: reads use only the ones you tick. Every answer is verified, so a
        poor choice costs availability, never correctness. Each account's reads stay with one of your operators.
        ENS names are mock placeholders; operators will mint real derpc.eth subnames
        in a later milestone.

3 · Verified reads

      

        Each value is proven with eth_getProof at the verified finalized block, through the worker and
        your operators. A repeat at the same block comes from the on-device cache. Public addresses only.
